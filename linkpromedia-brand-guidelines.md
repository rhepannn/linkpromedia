# LinkProMedia — Brand Guidelines

Dokumen panduan identitas visual LinkProMedia (sebelumnya Wartalink).
Untuk detail warna, lihat [linkpromedia-color-palette.md](./linkpromedia-color-palette.md).

---

## Nama Brand

| Bentuk | Penggunaan |
|---|---|
| `LinkProMedia` | Penulisan baku di teks, judul, metadata |
| `LinkPro Media` | Logo di header, footer, sidebar admin, halaman login |
| `linkpromedia.id` | Domain, URL, alamat email |
| `LINKPROMEDIA` | Top bar header (huruf kapital, tracking lebar) |
| `@linkpromediaid` | Akun sosial media (Twitter/X, dll.) |

**Jangan** gunakan lagi nama lama: ~~Wartalink~~, ~~Warta link~~, ~~WARTALINK~~.

## Logo

Logo berupa teks dua warna, tanpa ikon:

```
LinkPro  → warna primary-600 (#0C447C)
Media    → warna gray-900 (#111827) atau putih di atas latar gelap
```

### Varian

| Lokasi | Bagian 1 | Bagian 2 |
|---|---|---|
| Header (latar putih) | `LinkPro` navy `#0C447C` | `Media` abu gelap `#111827` |
| Footer (latar gelap) | `LinkPro` biru `#185FA5` | `Media` putih `#FFFFFF` |
| Sidebar admin | `LinkPro` navy `#0C447C` | `Media` abu gelap `#111827` |
| Halaman login | `LinkPro` navy `#0C447C` | `Media` abu gelap `#111827` |

### Aturan

- Font: bold/black (`font-black`), tracking rapat (`tracking-tight`)
- Ukuran: `text-2xl` di header/footer kecil, `text-3xl` di halaman login
- Dua bagian selalu berdampingan tanpa spasi tambahan
- Tidak diberi ikon, badge, atau dekorasi lain

## Warna

Ringkasan — detail lengkap di [linkpromedia-color-palette.md](./linkpromedia-color-palette.md):

| Peran | Warna | Hex |
|---|---|---|
| Utama | Navy Biru | `#0C447C` |
| Sekunder | Biru | `#185FA5` |
| Aksen (terbatas) | Kuning | `#F0A400` |
| Latar | Putih / Abu terang | `#FFFFFF` / `#F7F8FA` |
| Teks | Gelap | `#1A1D29` |

**Catatan penting:**
- Merah **bukan** warna brand. Merah hanya dipakai untuk state error/validasi form dan aksi destruktif (tombol hapus).
- Kuning aksen hanya untuk badge kecil ("Breaking News", "Terbaru"), bukan latar besar.

## Tipografi

- Font utama: Geist Sans (`--font-geist-sans`)
- Judul artikel: bold, warna `#1A1D29`
- Body artikel: regular, warna `#374151`
- Link dalam artikel: biru sekunder `#185FA5` + underline
